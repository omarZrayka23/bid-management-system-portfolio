# Bid Management System

## Overview

A full-stack enterprise application for managing prequalifications,
tenders, submissions, approvals, and documents.

## Technologies

- React
- TypeScript
- Material UI
- ASP.NET Core
- Entity Framework Core
- SQL Server

## Architecture

React Frontend
        ↓
ASP.NET Core Web API
        ↓
Entity Framework Core
        ↓
SQL Server
